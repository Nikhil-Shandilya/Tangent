# User Stories — Portfolio Management System

This document captures user stories gathered from prospective users to guide the design and prioritization of the Portfolio Management System.

## Personas & Stories

### Mr Sharma (71)

> "Most of my retirement savings are low-risk. I want to see all my investments—such as stocks, mutual funds, bonds, gold, and fixed deposits—in one place, with a clear breakdown of their current value and overall performance."

### Ms Iyer (69)

> "Before making any new investments. I want to compare different investment options, such as mutual funds, ETFs, bonds, and stocks, using simple charts and historical performance, so I can make informed financial decisions."

### Ms Goyal (73)

> "My savings are spread across seven types. I want to understand how my money is distributed across different asset classes, so I can easily identify whether my portfolio is balanced or overly dependent on a single type of investment."

### Mr Agarwal (70)

> "I rely on my investments to generate regular income. I want to track the income generated by my investments, including dividends, bond interest, and other payouts, in a single view so I can better plan my monthly finances."

### Mr Singh (65)

> "I want to monitor investments that I am interested in, even if I haven't purchased them yet, so I can compare their performance with my existing portfolio before making future investment decisions."
